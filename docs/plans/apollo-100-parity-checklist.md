# Apollo 100% 功能/欄位對齊清單

目標：介面不照抄 Apollo 視覺，但每個功能、欄位、篩選、表格欄、按鈕流程、匯入匯出與權限語意要對齊。

狀態定義：
- `done`：已有真資料模型/API/UI 流程。
- `partial`：已有主要流程，但缺 Apollo 細欄位、次流程或批次功能。
- `surface`：只有入口或操作骨架，尚未完整落地。
- `missing`：尚未實作。
